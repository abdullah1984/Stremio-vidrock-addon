# Stremio VidRock Addon

إضافة Stremio لتشغيل الأفلام والمسلسلات من موقع VidRock.net مباشرة في تطبيق Stremio.

## المميزات

- ✅ دعم الأفلام والمسلسلات
- ✅ استخدام معرفات IMDB
- ✅ واجهة بسيطة وسهلة الاستخدام
- ✅ نشر دائم على Render

## التثبيت

### الطريقة 1: استخدام الرابط المباشر
انسخ رابط المانيفست التالي والصقه في Stremio:

```
https://your-app-name.onrender.com/manifest.json
```

### الطريقة 2: النشر على Render

1. سجل دخولك في [Render.com](https://render.com) باستخدام حساب GitHub
2. اضغط على **New +** ثم اختر **Web Service**
3. اختر مستودع `stremio-vidrock-addon`
4. اترك الإعدادات الافتراضية واضغط **Create Web Service**
5. انتظر اكتمال النشر (حوالي 2-3 دقائق)
6. انسخ الرابط الذي يعطيك إياه Render

## الاستخدام

1. افتح تطبيق Stremio
2. اذهب إلى **Add-ons**
3. الصق رابط المانيفست في خانة البحث
4. اضغط **Install**
5. ابحث عن أي فيلم أو مسلسل
6. ستجد خيار **VidRock Player** متاحاً

## التطوير المحلي

```bash
# تثبيت التبعيات
npm install

# تشغيل الخادم محلياً
npm start

# الإضافة ستكون متاحة على:
# http://localhost:7000/manifest.json
```

## البنية

- `index.js` - ملف الإضافة الرئيسي
- `package.json` - التبعيات والإعدادات
- `Dockerfile` - لتشغيل الإضافة في حاوية Docker
- `render.yaml` - إعدادات النشر على Render
